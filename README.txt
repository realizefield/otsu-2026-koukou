・熊本県庁・山鹿市との併願についての質問も含みます。
・面接カード①②（長所・短所／好きな科目／趣味・特技／最近関心を持った事柄／志望動機／やってみたい仕事／がんばってきたこと／自己PR）と、想定問答集をもとに作った、58問の練習ページです。
・大卒版と同じ仕組みです（録音・時間・目安点・AI採点・成績の記録）。問題と模範例だけを、高校生向けに作り直しました。
・氏名は入れていません。ページの入力欄も「生徒番号またはニックネーム」です（実名でなくてかまいません）。
・黄色の〔 〕は、自分の事実で埋める部分です（部員数、成績、練習回数、家族の反応など）。

 1. 導入・緊張（5問）          緊張、前日の睡眠、待ち時間、面接の練習
 2. 志望動機・大津町の理解（17問）  志望動機、熊本県庁・山鹿市との併願（理由、違い、志望順位、合格した場合）、なぜ教員ではないか、志望度、町の魅力・課題、将来像
 3. 面接カードの深掘り（10問）   自己PR、長所・短所、力を入れたこと、やってみたい仕事、インターン、通信制高校、こども医療、役場の方の話
 4. 経験・人柄（11問）         周りからの評価、頑張り屋か、主将・会長、成績、ストレス、臨機応変、失敗、カードは自分で書いたか
 5. 公務員としての意識・時事・災害（7問）
 6. 仕事・働き方・家族・将来（6問）
 7. 最後の質問・逆質問（2問）
 ※熊本県教育事務の面接で実際に聞かれた質問の類型を含みます（「質問の意図」に表示）。

【言葉のくせのチェック】
 「〜に対して」「最も大事なことは」などの言い回しを使うと、アドバイスに言い換えの例が表示されます（目安点の「話し方」も少し下がります）。
 ホームの「言葉のくせを直す（言い換え集）」にも、言い換えの例を載せています。

【1. 合言葉を変える】
 現在の合言葉は「otsu-koko2026」です。必ず変更してください。
 index.html#setup を開き、新しい合言葉を入力 → 表示された passHash の行を config.js に貼り付けます。

【2. 事前に必ず確認すること（ページの「直前までに確認すること」にも載っています）】
 ・町の将来像は「今も未来もみんなが幸せであり続けられるまち」（「みんなで」ではありません）。
 ・通信制高校は、町の施政方針では「誘致」。現在の状況を町の公式サイトで確認します。
 ・こども医療は、対象が満18歳に達する日以降の最初の3月31日まで。自己負担の有無は未確認のため、「無料」と断定せず「助成」と言います。
 ・〔 〕を、すべて本人の事実で埋めます。うその数字は、深掘りで必ず崩れます。

【3. 読み上げ音声を作る（VOICEVOX・任意）】
 VOICEVOXを起動したまま、このフォルダで  python make_audio.py
 audio フォルダができるので、index.html と同じ場所に置きます。
 音声がない間は、ブラウザ内蔵の声で読み上げます。ホームの「ブラウザの声」で声を選べます（Chromeの「Google 日本語」がおすすめ）。
 読み上げの声が使えない端末では、「隠す」設定でも質問の文字を表示します。
 VOICEVOXと各キャラクターの利用規約・クレジット表記（ページ下に自動表示）をご確認ください。

【4. 公開する】
 GAMBAや大卒版と同じように、GitHubのページ等に置いて、URLと合言葉を生徒さんに伝えます。
 ※フォルダ名は大卒版と分けてください（記録は端末ごとに、別のキーで保存されます）。
 ※合言葉は簡易的な入口です。URLを知っている人が見ようと思えば、ページの内容は見られます。

【5. AI採点とGoogleスプレッドシート記録（任意）】
 ・すでに大卒版で設定ずみの場合：大卒版の config.js の endpoint と appToken を、この config.js にコピーするだけで使えます。
   記録は同じスプレッドシートの「成績ログ」に溜まり、「問題集」の列で大卒版と区別できます。
 ・採点の指示を高校生向けに調整したい場合は、この Code.gs の中身を Apps Script に貼り直し、「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」で更新します。
   ※大卒版も同じスクリプトを使っている場合、採点の指示は両方に反映されます。別にしたい場合は、新しいスプレッドシートで作り直してください。
 ・新しく作る場合の手順は、大卒版の「AI採点とGoogle記録の設定手順」と同じです。
 ・記録されるのは、ニックネーム・問題・点数・良かった点・改善点・話した秒数のみです（音声と回答全文は保存しません）。
 ・生徒さん（未成年は保護者）に、ニックネーム・回答の文字・点数をGoogleと採点AIに送ることを説明し、同意を得てからお使いください。
